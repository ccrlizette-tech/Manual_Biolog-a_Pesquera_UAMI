**Práctica 02. Crecimiento relativo y alometría**

Análisis del crecimiento relativo en peces mediante la relación entre diferentes variables morfométricas. A través de modelos de regresión y la estimación del coeficiente alométrico (b), se identifican patrones de crecimiento isométrico, alométrico positivo y alométrico negativo, proporcionando herramientas para interpretar los cambios en las proporciones corporales y su aplicación en estudios de biología pesquera.
La base de datos (DATOS DE PRÁCTICA.xls) puede modificarse y adaptarse de acuerdo con los objetivos de enseñanza del docente. Si se utiliza una base de datos diferente, únicamente será necesario actualizar el nombre del archivo correspondiente en el script para garantizar su correcta ejecución.
