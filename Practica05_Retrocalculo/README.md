**Práctica 05. Retrocálculo de tallas en peces**

Estimación retrospectiva de las longitudes de peces a edades anteriores mediante el análisis de la relación entre el crecimiento somático y el crecimiento de estructuras duras, como escamas y otolitos. A través de la aplicación de los métodos de Dahl-Lea y Fraser-Lee, se reconstruyen las tallas correspondientes a los primeros grupos de edad, proporcionando herramientas para el estudio del crecimiento individual y poblacional en biología pesquera.
La base de datos (Retrocalculo.xls) puede modificarse y adaptarse de acuerdo con los objetivos de enseñanza del docente. Si se utiliza una base de datos diferente, únicamente será necesario actualizar el nombre del archivo correspondiente en el script para garantizar su correcta ejecución.
