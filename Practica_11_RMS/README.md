**Práctica 11. Estimación del rendimiento máximo sostenible (RMS): modelo holístico de Schaefer**

Estimación del rendimiento máximo sostenible (RMS o MSY) mediante la aplicación del modelo de producción excedente de Schaefer. A partir de datos históricos de captura y esfuerzo pesquero, se calcula la captura por unidad de esfuerzo (CPUE), se ajusta un modelo de regresión lineal y se estiman el rendimiento máximo sostenible y el esfuerzo pesquero óptimo. Estos análisis proporcionan herramientas para evaluar la relación entre la intensidad de explotación y el rendimiento de una pesquería, contribuyendo al manejo sostenible de los recursos pesqueros. No hay base de datos para esta práctica el ejercicio es sugerido en la práctica impresa, el script P11 puede ser adaptado de acuerdo a los objetivos del docente desde la sección 3.
